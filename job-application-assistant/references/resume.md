# 中文一页简历创建与模板微调

本参考用于 `创建简历` 和 `微调简历`。先执行 `facts-and-jd.md` 的资料、事实、岗位与多项目门控；所有个人与项目事实来自当次上下文、授权档案、项目资料或知识库，技能本身不提供个人事实。

## 1. 共用内容规则

- 每次只处理一个岗位，固定中文、一页；不生成英文简历、多页简历或 Word 成品。
- 只写已确认或有证据支持的身份、教育、技能、项目、贡献、证书和数据。不得为了匹配岗位补写经历、熟练度或指标。
- 根据岗位描述（Job Description，JD）调整内容选择与顺序，突出相关证据，省略无支持内容。
- 项目外技术只有在用户确认本人具备相应认知或使用经验后，才能列入专业技能；只写技术名称，不标“熟悉”“掌握”“了解”，不加入未使用该技术的项目。
- 团队项目贡献未经确认不得写成个人成果；证据不足或未经确认的数值不得写入。
- 简历正文保持书面简洁，不加入术语类型解释、教学性括注或面向用户的对话语言。
- 英语 CET-6（大学英语六级）、其他证书、排名和 JD 未要求字段只有在授权资料已确认且本次适用时才写入，不作为默认个人事实。
- 写入前确定用户指定或配置的输出目录；不得写入技能目录、项目源仓库、知识库或原始模板。已有文件按归档规则保留版本，不静默覆盖。

## 2. 从零创建简历

1. 确认 JD、必要身份与教育事实、可用技能和项目证据；多个候选项目必须先确认清单与顺序。
2. 形成内容预算，通常包含基本信息与求职意向、教育背景、专业技能、最相关项目经历；其他板块只在本页确有空间且事实相关时加入。
3. 先创建 Markdown 源稿。源稿是事实与内容的基准，不写入无依据占位内容。
4. 使用当前智能体运行框架的原生能力生成 PDF；可保留 TeX 工作源以支持渲染与复用，但不绑定特定渲染器。
5. 交付 Markdown 源稿和 PDF 成品；保留的 TeX 工作源一并放入同一岗位版本目录。
6. PDF 未生成或任一自动检查失败时，可以保留阶段成果并说明失败步骤，但不得宣称任务成功。

## 3. 基于 TeX 模板和原 PDF 微调

1. 确认 JD、原 TeX 模板、原简历 PDF 和必要事实资料均已提供且可读取；缺少任一必需输入时先追问。
2. 记录原 TeX 与原 PDF 的路径和内容哈希，读取原 PDF 的页数、文本和版面作为参照。
3. 在岗位输出目录另存新的 TeX 工作文件，之后只编辑副本。原 TeX 和原 PDF 始终只读。
4. 只允许修改关键词、事实性措辞、要点内部顺序，以及项目、技能和其他内容板块的选择与顺序。
5. 不得修改原模板整体版式、字体、配色或页面结构；不得把其他模板样式混入副本。
6. 渲染新 PDF，并比较原 TeX 与新 TeX，确认差异仅为允许的内容与顺序变化，或下述允许的应急间距收缩。
7. 交付新的 TeX 工作源与新 PDF，豁免 Markdown 源稿。原文件哈希必须保持不变。

## 4. 单页溢出与内容删减

1. 内容首次超出一页时，不得直接交付，也不得擅自删除事实或板块。
2. 对从零创建的自建版面，可先修正明显的排版空间浪费；对模板微调，只允许既定的轻微间距收缩，例如 section 间距从 0.20em 调至 0.12em，不得改字体、配色或页面结构。
3. 纯版式收缩后重新生成并执行全部检查；仍超一页时，列出建议保留与删除的具体内容、理由及影响。
4. 用户确认删减清单后才修改内容并生成最终版。用户未确认前只能交付建议和阶段稿，不标记为正式成功。

## 5. PDF 自动质量检查

使用当前框架可用的 PDF 读取、文本提取、坐标检查、渲染和文件比较能力执行；不得用“文件已生成”代替检查。每项记录通过、失败或无法执行，无法执行等同未完成验收。

1. 编译或生成过程无错误。
2. 页数恰好为 1。
3. 中文文本可提取且所需字体、字符映射有效，无乱码或缺字迹象。
4. 正文存在可复制文本层，必要板块和核心内容未缺失。
5. 文本与图形坐标未越出页面可见区域；检查文本块异常重叠、裁切和明显空白异常。仅靠文本提取不足以判断时，使用框架的渲染或版面检查能力补查。
6. 模板微调中，除允许的内容、顺序和应急间距变化外，无字体、配色和页面结构差异。
7. Markdown 或 TeX 交付源与 PDF 中的身份、教育、技能、项目、贡献和数值逐项一致。
8. 去除空格与换行后，PDF 文本层可检索到求职意向、届次或毕业时间、公司或岗位名，以及当次 JD 核心关键词；某项不适用时须说明原因，不得静默跳过。

只有全部适用检查通过后才能标记交付成功。失败后修复并重检；仍失败则明确列出失败项，保留阶段成果，不宣称完成。

## 6. 交付前检查

- 从零创建是否同时存在 Markdown 与一页 PDF；模板微调是否交付新 TeX 与一页 PDF。
- 所有个人事实是否来自授权来源，项目外技能、历史数据和团队贡献是否已按规则确认。
- 内容删减是否经用户确认，原 TeX 和原 PDF 是否保持不变。
- 自动检查是否有实际执行结果，源文件与 PDF 的核心事实是否一致。
